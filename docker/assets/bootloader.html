Bootloader mode

Puts a CircuitPython device (e.g. a PaintAudio MIDI Captain) into bootloader mode, so a firmware (.uf2) can be copied to it.

  1. Use Chrome or Edge (other browsers do not support this). Open this file directly from your computer.
  2. Connect the device via USB and switch it on normally (no switch held).
  3. Click the button and select the device in the list (usually named Pico or CircuitPython), then Connect.
  4. The device restarts and a drive named RPI-RP2 appears. Copy the .uf2 file onto it; the device restarts with the new firmware.
